# Personal Portfolio Website

A modern, full-stack personal portfolio website showcasing projects, skills, and professional experience.

## 🚀 Live Demo

**Website**: [prakash-chaudhary-portfolio.vercel.app](https://prakash-chaudhary-portfolio.vercel.app)

## ✨ Features

- 🎨 Modern, responsive design with dark/light mode
- 📱 Mobile-first approach
- ⚡ Fast performance with optimized loading
- 🔐 Secure admin dashboard for content management
- 📧 Contact form with message storage
- 🎯 Project showcase with filtering
- 📄 Resume/CV section
- 🌐 SEO optimized

## 🛠️ Tech Stack

**Frontend**
- React 18 + Vite
- Tailwind CSS
- Framer Motion
- React Router

**Backend**
- Node.js + Express
- MongoDB + Mongoose
- JWT Authentication
- Security: Helmet, Rate Limiting, Input Validation

## 📦 Installation

### Prerequisites
- Node.js v16+
- MongoDB

### Setup

1. Clone the repository
```bash
git clone https://github.com/prakashkchaudhary/prakash-chaudhary-portfolio.git
cd prakash-chaudhary-portfolio
```

2. Install dependencies
```bash
# Backend
cd backend
npm install

# Frontend
cd ../frontend
npm install
```

3. Configure environment variables
```bash
# Backend: Create .env from .env.example
cd backend
cp .env.example .env
# Edit .env with your configuration

# Frontend: Create .env from .env.example
cd ../frontend
cp .env.example .env
# Edit .env with your backend URL
```

4. Start development servers
```bash
# Backend (from backend directory)
npm run dev

# Frontend (from frontend directory)
npm run dev
```

## 🚀 Deployment

- **Frontend**: Deployed on Vercel
- **Backend**: Deployed on Render
- **Database**: MongoDB Atlas
